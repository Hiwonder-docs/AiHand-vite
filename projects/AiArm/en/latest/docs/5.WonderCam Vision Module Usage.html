5. WonderCam Vision Module Usage ​

5.1 Color Recognition ​

  1. In the preceding lessons, we covered the hardware details and functional features of the CoreX main controller and WonderCam vision recognition module. In this lesson, we will integrate the main controller with the vision module to delve into more AI applications.

  2. After recognizing red, green and blue objects, WonderCam vision module will relay this information to the main controller whose RGB lights illuminate in corresponding colors.

5.1.1 Preparation ​

  1. Command WonderCam module to learn red, green and blue colors referring to “1. WonderCam Vision Module Usage”.

  2. Connect WonderCam vision module to port 9 of CoreX controller.

  3. Install WonderCode programming software according to the instructions provided in “3. Scratch Programming”.

5.1.2 Program Logic ​

  1. The initial step involves initializing the vision module. This includes configuring the module's functionality, setting the initial position, and disabling the ultrasonic module. It is important to disable the ultrasonic module because its emission of light can potentially interfere with color recognition.

  2. Following the initialization, the program proceeds to verify if the learned colors are being recognized. Based on the outcome of this verification, the hardware on the main controller provides corresponding feedback effects.

  3. For detailed implementation of this game, please refer to the 5. Program Analysis section.

5.1.3 Connection ​

  1. Connect the CoreX controller and computer using USB cable, then turn on the controller.
  1. Open “WonderCode” software.
  1. Click on the located at the lower left corner and select AiArm from the available options.
  1. Click-on and select the corresponding COM port, for example COM4. Please note that COM port options may differ from each computer.

NOTE

please do not select COM1, as it used for communication port in general.

  1. Once the connection is established successfully, the below prompt will appear.

  1. Initial Settings

​ (1) To begin, the initialization process will involve initializing port 9, which is connected to WonderCam vision module. Following this, the mode of WonderCam will be switched to color recognition. To avoid any potential interference with color recognition, the ultrasonic module will be turned off.

​ (3) A variable named target area will be established, with an initial value of 0. The detected area value of the color block will be assigned to this variable, allowing for further processing or analysis.

Once these values are obtained, the area of the block image can be calculated. Subsequently, the following condition can be used to determine if the block area meets the specified threshold, confirming the identified object as the red block.

​ (2) If AiArm detects the color of the block is ID1 (red), set the color of LED light to red. At this time, RGB light on CoreX controller will illuminate in red. If no color is recognized, CoreX controller’s light will go off.

  2. Upon receiving the information, the main controller triggers the buzzer to emit a brief sound, repeating the number of times corresponding to the tags ID.

  1. When you press the specific key on the main controller, AiArm can switch different game mode.

  1. Initial Settings

​ (1) To establish the initial position for AiArm, an action group labeled as 0 will be called. Subsequently, a loop function will be employed to check for any input command involving the key. In the absence of any command input, AiArm will remain in the initial position while the light on the CoreX controller illuminates in white.

NOTE

​ (2) To enable game switching using the key, a loop will execute until another command is received. As long as key B is not pressed, the color recognition program will continue to run. However, once key B is pressed, the current program will exit, and the program will switch to the tag recognition program.

5.4.4 Program Analysis ​

  1. Initial Settings

​ (1) To begin, the initialization process will involve initializing port 9, which is connected to WonderCam vision module. Following this, the mode of WonderCam will be switched to barcode recognition. To avoid any potential interference with barcode recognition, the ultrasonic module will be turned off.

​ (2) Then, turn on the fill light on WonderCam module. Next, an action group labeled as 0 will be invoked to position the robot arm in a downward attitude, facilitating efficient barcode recognition.

​ (3) A variable named LED light will be established, with an initial value of 0. This variable refers to the number of CoreX controller’s light that will light up when WonderCam recognizing barcodes.

NOTE

action groups 0-30 are encrypted and serve as the mandatory action groups for robot games. If you intend to create a new action group, kindly ensure that you begin saving it from No. 31 onwards.

  1. Barcode Recognition

​ (1) WonderCam incorporates barcode recognition functionality. A repetitive loop statement is employed to enable the vision module to continuously recognize tags.

  1. Recognition Feedback

​ (1) To configure the recognition feedback, lets consider the example of using light 0 in WonderCams barcode recognition process. When WonderCam detects a barcode, light 0 will be turned on for 0.5 seconds before turning off. At the same time, a variable called LED light will be incremented from 0 to 1, indicating the change from LED=0 to LED=1.

​ (2) The program will then proceed to check if WonderCam's vision module recognizes the barcode. If the barcode is successfully recognized, light 1 will be illuminated briefly and then turned off. This cycle will continue for the remaining lights. Subsequently, the variable will be reset to 0, and the loop will restart.

​ (3) If the barcode is removed from WonderCam's recognition zone, indicating that no barcode is currently being recognized, the program will exit the loop. In this case, the variable LED light will be set to 0. WonderCam will then resume its barcode recognition process and perform the above operations again.
